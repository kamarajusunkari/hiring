# Arora Tech Solutions – Developer Hiring Solutions
**Modern React Single Page Application for `hire.aroratechsolutions.com`**

> "Your Next Developer Is Just One Step Away."

This repository contains the **React 18 + Vite** lead generation and developer staffing platform for **Arora Tech Solutions**. It operates independently on a dedicated subdomain (`hire.aroratechsolutions.com`), ensuring the existing WordPress corporate site (`aroratechsolutions.com`) remains completely untouched.

---

## Architecture & Tech Stack

- **Framework:** React 18 + Vite
- **Routing:** React Router v6 (`/`, `/hire/:roleSlug`, `/contact`)
- **Iconography:** Lucide React (clean, lightweight 1.75px SVG icons)
- **Styling:** Custom CSS Design Tokens, fluid typography with `clamp()`, 8px spacing grid, glassmorphism, and WCAG 2.2 AA accessibility.
- **State & Leads:** Real-time client-side validation, instant feedback, automatic backup to `localStorage` (`arora_leads`), and simulated or webhook API dispatch.
- **Performance:** Sub-second routing, lazy code splitting, zero server compilation overhead.

## Running Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### 3. Production Build
```bash
npm run build
```
The optimized production files will be output to the `dist/` directory, ready to deploy to Netlify, Vercel, Cloudflare Pages, AWS S3, or cPanel.

### 4. Preview Production Build Locally
```bash
npm run preview
```
